• Overview: A production-ready, full-stack appointment booking and payment platform built with React, TypeScript, Python (Flask), and PostgreSQL.
• Key Features: Database-level double-booking prevention (UNIQUE constraints), server-side pricing and payment verification, automated .pdf receipt generation (fpdf2), Resend API transactional emails, JWT-protected provider admin portal, and automated pytest security testing.
• Tech Stack: React, TypeScript, Vite, Python 3, Flask, PostgreSQL (Neon Cloud), Resend API, Pytest, Render, and GitHub Pages.
• Quickstart & Commands: Local setup via pip install -r requirements.txt, python -m pytest, and python booking_server.py, followed by standard Git commit and push workflows.
